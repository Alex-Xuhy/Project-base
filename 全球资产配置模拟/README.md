# 全球资产配置模拟

厦门大学 econlab「全球财富管理2027模拟投资」的量化投资项目。

- **站点**：https://econlab.xmu.edu.cn/trade/trade/index
- **比赛期**：**只有 2 个月**（见下方订正）｜站点项目页写 2026-09-05 ~ 2027-06-30
- **初始资金**：1,000,000（人民币计价）
- **硬约束**：`weekendConstraint=1` —— **只能在周末调仓**
- **数据节奏**：股票数据更新到**周三**，汇率更新到**周五**
- **既定方向**：投资期限短 + 全球资产池 → 优先**动量策略**

> ⚠ **赛期订正（2026-09-20 用户口述，以此为准）**：实际比赛**只有 2 个月**，
> 不是站点项目页写的 10 个月（2026-09-05 ~ 2027-06-30）。站点日期疑为项目容器期
> 而非计分赛期。后果：
> - 周末调仓 + 2 个月 → **只有 8-9 次调仓机会**（月频只够 2 次）
> - **无交易成本** → 换手约束不适用，周频调仓免费，许多实盘禁区被放开
> - **年化口径一律废弃**，评估改用「所有历史 **8 周窗口**的收益分布」
>   （中位 / 5% 分位 / 最差 / 跑赢基准占比）

## 一、资产池

**80 只美股 ETF**，全部美元计价（汇率序列全池一致，都是 USD/CNY）。
其中 HTEC 已停更，实际可用 **79 只**。

**完整分类图 + 中文明细清单见 [`2. 资产池认知/T_资产池清单.md`](2.%20资产池认知/T_资产池清单.md)**
（由 `2b_功能分类冗余度.py` 生成，改动后重跑即可，别手改）。
站点自带的 4 大类 / 11 子类分类如下，但**粒度太粗且有 15 处会误导策略**，
本项目改用按「实际靠什么赚钱」重建的**功能分类**：

| 站点大类 | 站点子类 |
|---|---|
| Equity 股权类 | DevelopedMarket 发达市场、developingMarket 新兴市场、otherMarket 其他市场 |
| FixedIncome 固定收益类 | corporateBond 公司债券、nationalBond 国家债券 |
| Commodity 大宗商品类 | otherCommodity 其他商品、nobleMetal 贵金属、energy 能源、agriculturalProduct 农产品 |
| Currency 货币基金类 | dollar 美元、otherCurrency 其他货币 |

站点分类的几处典型错标（完整 15 条见清单）：
- **IBIT** 被归到「商品」—— 实为加密资产，风险来源与商品无关
- **GDX / SIL / XME / SLX / URA / MOO / IGE** 被归到「股权」——
  实际是黄金/白银/金属/钢/铀/农产品的代理，不是股票
- **TLT** 被归到「固收/国家债券」—— 但久期 20 年+，**波动接近股票**
- **UDN 与 UUP** 被归到同一格「美元」—— 但一个做多一个做空，完全负相关

⚠ **HTEC（stockId=46）自 2025-06-25 起停更**，是僵尸标的，建模时需剔除或特殊处理。

## 三、使用方法

### 1. 取 token（约 30 分钟过期，每次拉数前都要做）

浏览器登录站点后，F12 → Console 执行：

```js
document.cookie.split('; ').find(c=>c.startsWith('Client-Token='))?.slice(13)
```

把结果写进项目根目录 `_token.local`，或直接 `--token` 传入。

### 2. 跑脚本 —— 5 个步骤，每步一个 `run.py` 入口

**不用记 14 个文件名**：每步文件夹里都有一个 `run.py`，按序跑本步全部子脚本。

```bash
python "0. Scripts 脚本/run_all.py"              # 按 1→5 顺序跑全部 5 步
python "0. Scripts 脚本/run_all.py" --list       # 只列清单，不跑
python "0. Scripts 脚本/run_all.py" --skip 1     # 跳过第 1 步（没 token 时最常用）
python "0. Scripts 脚本/run_all.py" --only 3     # 只跑第 3 步
```

单步也能直接调用，或用 `--only` 只跑其中一个子脚本：

```bash
python "0. Scripts 脚本/3. 大类与状态检验/run.py"            # 本步全部
python "0. Scripts 脚本/3. 大类与状态检验/run.py" --list     # 只列清单
python "0. Scripts 脚本/3. 大类与状态检验/run.py" --only 3c  # 只跑 3c
```

第 1 步的三个子脚本要联网（`1a` 还要 token），也可以单独调用：

```bash
python "0. Scripts 脚本/1. 取数与复权/1a_拉取日线汇率.py"   # 全量/增量刷新，80 只约 33 秒
python "0. Scripts 脚本/1. 取数与复权/1b_拆股复权.py"       # 复权（新增拆股时重跑）
python "0. Scripts 脚本/1. 取数与复权/1c_补站点缺口.py"     # 补站点滞后的最近几日（见下）
```

`run.py` 默认**遇错即停**（下游脚本读到半截产物会算出静默错误的数字）；要强行跑完加 `--keep-going`。
`--` 之后的参数透传给每个子脚本，例如 `-- --token XXX`。

`1b --check-only` 可在不动数据的前提下单跑拆股检测器。

### 3. ⚠ 站点数据的滞后缺口（每次调仓前都要补）

站点股票数据**固定滞后到周三**，而调仓只能发生在周末 —— 也就是说，
**周三到周末之间的全部行情，站点里根本不存在**，而那正是做决策的时点。

`1c` 从 stockanalysis.com 补齐，并强制两道校验：与站点在重叠日逐只对账
（2026-09-16 实测 79/80 残差 < 1e-5）、缺口段量级合理性断言。

> ⚠ **拼接只能用相对收益，绝对水平锚定站点末日**：
> `ext[缺口] / ext[站点末日] × site[站点末日]`。
> 写成 `ext[缺口] × site[站点末日]` 会把绝对价乘上去，量级直接爆掉
> （真实踩过：缺口期收益从 +0.7% 变成 +36246%，而「历史未变」的断言照样通过 ——
> 因为它只覆盖站点末日及以前）。`1c.stitch()` 里两道断言就是为此加的。

`wide_close_extgap_usd.csv` **只用于「当前读数」类分析**；
任何历史收益/动量/回测仍必须用站点原始序列。

## 四、⚠ 最重要的一条：数据未做拆股复权

站点提供的价格**未做拆股复权，且复权处理不一致**。两种矛盾形态都出现过：
价格跳变与 `changePercent` 一致（XLK 拆股没复权），或两者矛盾
（PSP 价格 +399.9% 但字段写 -0.03%）。反向证据也有：USO 真实 1:8 反拆日
2020-04-28 价格是平滑的，说明那次复权过了。**所以不能一刀切，必须逐事件核验。**

**已用外部来源逐一验证的 8 个事件**（见 `splits.csv`）：

| 标的 | 日期 | 比例 |
|---|---|---|
| XLK / XLY / XLE / XLU / XLB | 2025-12-05 | 2:1 正拆 |
| PSP | 2023-07-17 | 1:5 反拆 |
| UNG | 2024-01-24 | 1:4 反拆 |
| MJ | 2025-02-21 | 1:12 反拆 |

**不复权的后果**（12 个月动量，终点 2026-09-16）：

| 标的 | 复权前 | 复权后 |
|---|---|---|
| XLE | −28.7%（排名 73/80） | **+42.6%（排名 8/80）** |
| XLK | −32.5%（排名 75/80） | **+35.1%（排名 12/80）** |
| XLB | −44.5% | +11.1% |
| XLY | −54.5% | −9.0% |
| XLU | −50.9% | −1.8% |

**动量策略会把池内最强的资产当垫底剔除**。任何收益/动量计算都必须用 `prices_adj.csv`。

### 拆股判别的坑（复用 `1b` 检测器时注意）

- 只匹配**真正的标准拆股比率**（2/3/4/5/6/7/8/10/12/15/20 及其倒数），容差 ~1.5%。
- ⚠ **不要把 3:2、5:4、3:4、5:6 这类非整数比纳入** —— 放宽后会把 COVID 崩盘
  （2020-03-12/13/16/18）和 2023-10-18 全市场下跌日误判成拆股。
- 辅助判据：**拆股是特异性事件**。若同日多只资产同时跳变，那是**行情**不是拆股。
  唯一已知例外是 2025-12-05 的 5 只 SPDR（State Street 设计性同日拆分）。
- 检测器**只告警、不自动应用**。自动应用有把真实崩盘误判成拆股的风险，
  新事件必须人工核验发行方公告后手工加入 `SPLIT_EVENTS` 表。

## 五、汇率口径（对账时会遇到）

股票数据更新到**周三**、汇率更新到**周五**，两者不同步。于是有两种口径：

| 口径 | 算法 | 用途 |
|---|---|---|
| **同期**（本仓库 `wide_close_adj_cny.csv`） | 股票价 × **当日**汇率 | 算收益、算动量 |
| 站点 `latestStockPriceCny` | 股票价 × **最新**汇率 | 站点给账户估值 |

2026-09-16 一例：同期口径用 6.7628，站点用 09-18 的 6.7521，差 **0.16%**。
**与站点对账时注意这个差**，不是数据错误。

> **重要简化**：80 只标的全部美元计价、共用**同一条**汇率序列，因此
> **汇率在截面比较中完全抵消** —— 按人民币算动量和按美元算动量，
> **排名完全相同**。汇率只在账户层盈亏汇总时才起作用。

## 七、2026-09-16 加息：补缺口后的复核结论

FOMC 9/16 全票加息 25bp（3.75-4.00%，2023-07 以来首次）。站点数据停在 9/16，
9/17-9/18 由 1c 补齐。**结论与直觉相反**（`3c_缺口后复核.py`）：

| | 9/15→9/16（FOMC 当天） | 9/16→9/18（站点缺失） |
|---|---|---|
| 原油 USO | −3.52% | **−1.50%** |
| 能源股 XLE | −2.88% | **+0.44%** |
| 钢铁 SLX | −0.37% | −0.09% |
| 白银 SLV | −0.83% | **+5.05%** |
| 黄金 GLD | −0.61% | **+2.41%** |
| 加密 IBIT | −0.16% | **+6.92%** |
| 科技 XLK | +0.10% | **+3.08%** |
| 标普 SPY | −0.44% | **+1.26%** |

**9/16 是一次单日的鹰派膝跳，除原油外全部在两天内收复。** 全池 79 只等权 +0.73%，
上涨 50 只 —— 「加息 = 风险资产崩」没有发生（92% 已提前定价，是 sell the rumor 行情）。

三条被修正的判断：
- **「SLX 反常下跌」错** —— 三日 −0.46%，等于没动。

## 八、2026-09-20 调仓决策：围绕「加息」构造？—— 数据不支持

**推翻了这条链**。评分口径同日改为**只看绝对收益**（不看夏普），下次调仓锁定 5 个交易日。

### 8.1 状态定义（事前可知，无未来函数）

- 利率方向 = TLT 过去 126 日收益 < 0（**TLT 涨 = 利率下行，符号别写反**）
- 油价方向 = USO 过去 126 日收益 > 0
- 当前 = **利率↑油价↑**（TLT −7.13%、USO +31.07%）

### 8.2 三条检验，逐条把假设打掉

**① 「加息」对权益没有解释力**（Part A 因子归因，8 周窗口）

利率(TLT) 的 R² 几乎全部来自固收系 —— 国债长 **1.00**、国债中长 0.88、债宽基 0.72；
对权益系 ≈0（美股行业 0.01、美股宽基 0.03、新兴市场 0.01）。油价只解释商品系。
权益的真正驱动是**全球风险偏好**（SPY：美股宽基 R²=0.96）。

个券层面（决策落在这一层）：真正跟油价的是 DBC 0.78 / USCI 0.57 / XLE 0.37；
**GLD/SLV/GDX 贵金属对三个因子 R² 全部 ≤0.09** —— 池内唯一不被宏观因子解释的一类。

**② 子类平均会稀释信号，必须落到个券**（Part B）

`能源` 子类的成分是 **USO(原油) + UNG(天然气)** —— **XLE 不在里面，它在 `美股行业`**。
UNG 对油价的 R² 只有 **0.02**，由天气/库存驱动，是独立赌注。
把 USO 和 UNG 平均，得到的子类数字什么都不像。

同时：**条件均值必须减去无条件基线才是信号**。SPY 在当前状态是 +1.59%，
看似顺风，但它无条件 8 周本就是 ~+2%、胜率 ~75% —— **超额 −0.39pp**，
"会涨"是股权溢价，不是这个状态的功劳。

**③ ★ 最关键：超额靠单一事件撑起**（Part E，判定性）

同一状态拆成 25 个连续段，**13 段里 7 段的 USO 前瞻为负**，方向正负相间
（−26.0% 到 +11.1%）。均值为正完全靠 2020-10~2021-08 那一根。

剔除 2021-2022 窗口后：

| | 全状态超额 | 剔除 21-22 后 |
|---|---|---|
| USO | +1.74pp | **+0.11pp** |
| XLE | +1.26pp | **+0.22pp** |
| UNG | +7.78pp | +2.91pp |
| SPY | −0.39pp | +0.36pp |

**不是腰斩，是归零。** 「加息 → 能源顺风」完全是 2021-2022 一段行情的产物。

油价动量分桶也**不单调**：`+0~15%` → +0.98%、`+15~25%` → +5.40%、
`+25~35%` → +3.22%、`+35~50%` → +6.12%、**`+50%以上` → +0.93%**。
最高档反而最差 —— 极端处开始反转。当前 USO_126=+31.07% 落在 `+25~35%` 档
（第 88 分位），该档超额约 +2.69pp，但只有 41 个重叠窗口 ≈ **5 个独立事件**。

### 8.3 结论

1. **入场折扣**是唯一 100% 确定的东西，但**一次性**、量级有限（多数标的 ±1% 内），
   且**补贴不了尾部**（USO 的 8 周 5% 分位是 −10% 量级）。
2. 「加息」不是选券依据 —— 利率维度独立增量 ≈0（加进油价条件只改变 −0.12pp）。
3. 该状态**不足以支撑集中押注**，连「倾斜」都要打折。
4. **没有任何子类保证未来 1 周不亏**（Part C，有效 t 全在 ±0.5 内）——
   锁 5 天的风险只能靠**仓位**管，不能靠**选标的**管。

### 9.2 ★ 折扣与平稳在结构上是对立的

## 十一、2026-09-21 加息 → 美元？加息 → 黄金？（`5a_利率美元黄金.py`）

### 11.6 结论

1. **「加息 → 美元走强」方向对、强度弱**（R² 0.08）、**分段不一致**

   → 可以当地图，不能当信号。
2. **黄金不是利率资产。** 它最相关的因子是美元（R² 0.23），
   而美元自己跟利率也只有 0.08。**两段弱链接串成的因果链不值得信。**
3. **白银对利率的 R² = 0.01** —— 几乎没有关系。SLV/SIL 的驱动另有来源。
4. **别用美联储消息交易黄金/美元。** 数据不支持这条路。
5. **持有 GLD 的理由不是「加息所以买黄金」**，而是
   **它和股票相关性 0.04**（见第十节：风险贡献 0.26x，唯一在吸收风险）。
   黄金在本池的无条件 8 周只有 **+0.89%、胜率 50.9%** ——
   它从来就不是收益来源，是**分散来源**。

## 十三、2026-09-21 池内热点与成交额异动（`5c_池内热点异动.py`）

用户问：「近期美国市场的投资热点/机构关注/资金流向（避险）主要在哪些板块？」

### 13.0 ⚠ 口径警告：成交额 ≠ 资金净流入

站点只给**成交量（股数）**，没有 ETF 份额（shares outstanding）历史，
所以**算不出真正的资金净流入**（净流入 = 份额变化 × 净值，需要
creation/redemption 数据）。本节能算的是**成交额异动**
（近 5 日均额 ÷ 前 60 日均额），它是**关注度/换手**的代理，
方向必须配合价格变动读：

| 组合 | 含义 |
|---|---|
| 放量 + 上涨 | 增量买盘 |
| 放量 + 下跌 | 增量卖盘 |
| 缩量 + 上涨 | 无人接力的上涨 |

下文一律写「成交额异动」，不写「净流入」。真正的机构流向只能从公开新闻取（13.4）。

### 13.6 结论

1. **避险的方向是「短端 + 现金类」，不是黄金也不是长债。**
   近 4 周避险组唯一为正的是 **UUP +1.72%**；长端 IEF −2.37% / TLT −1.32%
   比短端 SHY −0.95% 差得多。
2. **热点在「实物 + 数字」两头**：能源（+9.16%/4w）、商品宽基（+17.72%/13w）、
   加密（+11.70%/4w）是仅有的双正子类。
3. **外部最拥挤的医疗已经开始回落**（池内近 4 周 −2.32% / −4.08%），
   外部报告自己也在提示。**别按三个月前的叙事建仓。**
4. **注意 13.5 那两条不吻合**：金融是价格与流入背离；医疗是叙事已过期。
   **外部结论必须回池内验证，这一步不能省。**
5. 与第十二节独立互证：**UUP 在两条完全不同的路径上都被选中**
   （相关性/保底检验，与本节的热度/动量），这是它值得加仓的最强证据。
